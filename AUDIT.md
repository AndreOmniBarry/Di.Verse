## 3. Your OpenAI key: check it in 1 minute

OpenAI API billing is **prepaid credit**. If a payment failed or the credit ran out or expired, the key still exists but every call fails with HTTP 429 `insufficient_quota`. A deleted or rotated key fails with HTTP 401.

```bash
cp .env.example .env      # if you don't have one; then paste keys
node test-whisper.js      # prints "TEST PASSED" or FAIL status + message
```

| Result | Meaning | Fix |
|---|---|---|
| `TEST PASSED` | Key and credit are fine | — |
| `FAIL status: 401` | Key invalid, revoked or deleted | platform.openai.com → API keys → create a new key and put it in `.env` |
| `FAIL status: 429` + "quota" | **No credit**, which matches your abandoned payment | platform.openai.com → Settings → Billing → add credit (a few dollars covers testing) |

The operator page now shows the same diagnosis live. Do the same check for `ANTHROPIC_API_KEY` at console.anthropic.com (a 401 or "credit balance" error shows in the operator alert).

Cost guide: `whisper-1` is billed per minute of audio. Silence is no longer sent, so a 60-minute sermon costs well under 60 billed minutes. Check current per-minute pricing on OpenAI's pricing page before quoting customers. You can switch models with `TRANSCRIBE_MODEL` in `.env` without changing code.

## 4. Blockers left before a *commercial* test

1. **Non-KJV translations (decision needed).** NKJV, NIV, ESV, AMP, TPT, MSG, NLT and others are copyrighted. Today Claude recalls them from memory, which risks (a) wording that isn't exact, shown to a congregation as scripture, and (b) licensing problems for a paid product. Options:
   - **For the 3-day test (recommended):** ship KJV plus public-domain translations loaded into SQLite like KJV (ASV, WEB, YLT and Darby have public-domain texts available). Grey out the others in the dropdown or label them "beta, AI-recalled".
   - **Before charging money:** licensed access through a Bible text API (for example API.Bible) or a direct publisher licence for the translations churches ask for.
2. **Real-room accuracy.** The speech threshold (`SPEECH_RMS` in the worklet) is tuned for a laptop mic. Test with the church's mixer feed and adjust if the meter never shows SPEECH or never shows silence.
3. **Verse ranges** ("John 3:16 to 18") aren't supported. Only the first verse shows.
4. **Run on the target machine:** `npm ci` on the Mac (`better-sqlite3` is a native module), then `npm run seed` once (needs internet), then `npm start`.
